# 一、总体思路

1. 数据规模

| n | 思考方向 |
|-------|-------|
| n <= 20 | 回溯、暴力、状态压缩 |
| n <= 1000 | O(n^2) |
| n <= 10^5 | O(nlogn)/O(n) |
| n >= 10^6 | 尽量O(n) |
2. 数据结构
- 需要快速查找：哈希、二分、平衡树
- 先进后出：栈
- 先进先出：队列
- 不断取最值：堆
- 有层级关系：树、图
- 存在连续区间：滑动窗口、前缀和
3. 关键词
- “有序”“最小满足”“最大满足”：二分
- “连续子数组/子串”：滑动窗口、前缀和、双指针
- “所有可能”“排列组合”：回溯
- “最少次数”“最大收益”“方案数”：动态规划
- “局部最优”“最多/最少”：贪心
- “频率”“是否出现”“两数之和”：哈希
- “前序/中序/后序/层序”：树遍历
- “第 K 大/小”“实时最大最小”：堆
4. 先暴力后优化
重复计算、查找过慢、排序缺失、状态是否可以压缩

# 二、复杂度

| 复杂度      | 算法            |
|----------|---------------|
| O(1)     | 直接访问、哈希平均查找   |
| O(logn)  | 二分查找、堆        |
| O(n)     | 一次遍历、双指针、哈希计数 |
| O(nlogn) | 排序、堆处理全部元素    |
| O(n^2)   | 双重循环、简单动态规划   |
| O(2^n)   | 子集、回溯         |
| O(n!)    | 全排列           |

# 四、链表

1. 首先思考：是否需要dummy虚拟头节点？是否可以用快慢指针？是否需要反转链表？是否涉及两个链表的长度、相交、合并？指针修改时，是否需要先保存next？
2. 常见题型
 * 反转链表
```agsl
while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
}
```
 * 反转区间
```agsl
ListNode dummy = new ListNode(0);
dummy.next = head;

ListNode prev = dummy;
while (prev.next != null) {
    if (prev.next.val == target) {
        prev.next = prev.next.next;
    } else {
        prev = prev.next;
    }
}
```
